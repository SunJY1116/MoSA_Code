
# MoSA: Multi-Modal Semantic Anchors for Feature Alignment in Federated Recommendation

This repository contains the official PyTorch implementation of the paper: **"MoSA: Multi-Modal Semantic Anchors for Feature Alignment in Federated Recommendation"**.


## 🚀 Quick Start

To run the code with default settings:

```bash
python train.py

```

## ⚙️ Environment

Please ensure you have the following dependencies installed. You can install them using `pip`:

```bash
pip install -r requirements.txt

```

*Recommended configuration:*

* Python >= 3.8
* PyTorch >= 1.10
* NumPy
* SciPy
* (Add other libraries your code uses, e.g., `scikit-learn`, `pandas`)

## 📂 Dataset

The code is designed to work with the following datasets (as described in the paper):

* **NineRec-KU**
* **Amazon-Sports**
* **Amazon-Baby**

*Note: Ensure the dataset files are placed in the `data/` directory (or modify the data path in `config.py` / arguments).*
